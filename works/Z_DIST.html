Methylation Drift Explorer

Z is the fraction of stem cells that are methylated at one CpG site (Z = M / N). As stem cells divide, Z drifts toward a steady level (η) and spreads out between people. The heatmap shows how likely each value of Z is at each age; darker means more likely. Drag the sliders, or type any value into the boxes, to see how each parameter changes it.
